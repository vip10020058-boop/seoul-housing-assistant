플랫폼 기능 바로가기

AI 주거 도우미는 서울 청년월세지원 공고와 법령을 근거로 절차·서류 초안을 안내합니다. 대회 채점 API POST /ask는 별도 경로로 유지됩니다. 공고 요건과 일정은 해당 연도 서울시 공고에서 다시 확인하세요.

API 연결 설정

Upstage Solar와 법제처 Open API를 연결하면 실시간 법령 근거를 포함해 상담합니다. 입력한 키는 이 브라우저 탭 메모리에만 두고, 서버에는 저장하지 않습니다. 페이지를 새로고침하면 다시 입력해야 합니다.

연결 확인 시 인증 요청은 AI 주거 도우미 서버를 거쳐 각 제공기관에 전달됩니다. 키는 브라우저 저장소·파일·서버에 저장되지 않습니다.
